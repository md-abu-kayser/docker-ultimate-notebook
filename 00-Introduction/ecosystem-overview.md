# Docker Ecosystem

- **Docker Engine**: Core runtime.
- **Docker CLI**: Command line interface.
- **Docker Compose**: Define multi-container apps.
- **Docker Hub**: Public container registry.
- **Docker Desktop**: All‑in‑one installer + GUI.
- **Docker Swarm**: Native clustering.
- **BuildKit**: Next‑gen image builder.
- **Docker Scout**: Vulnerability analysis.
- **Notary / Content Trust**: Image signing.
- **containerd & runc**: Low‑level container runtimes.

These tools together make Docker the most complete container platform.
